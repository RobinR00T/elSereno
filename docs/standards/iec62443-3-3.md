# elSereno and ISA/IEC 62443-3-3

elSereno maps each read-only detection to the **system requirements (SR)**
of **ISA/IEC 62443-3-3**, *System security requirements and security
levels*. A finding on an OT segment is evidence that a specific SR is not
met for that conduit or zone. The mapping lives in
`internal/standards/iec62443.go`, keyed by protocol, and is carried
alongside the NIST and ATT&CK references in every output.

See the mapping with:

```bash
elsereno standards --standard iec62443
```

62443-3-3 is a licensed standard (ISA/IEC). elSereno cites requirement
numbers and short titles only; it does not reproduce the normative text,
and the mapping is elSereno's reading, not an ISA or IEC assessment.

## The requirements elSereno touches

| SR | Short title | Evidenced by |
|---|---|---|
| SR 1.2 | Software process and device identification and authentication | any unauthenticated OT protocol reachable across a conduit |
| SR 1.13 | Access via untrusted networks | an OT service reachable from an IT vantage (`scan --vantage`) |
| SR 2.1 | Authorization enforcement | a protocol that lets a stranger change state (TriStation, writeable OPC UA, S7 without a password) |
| SR 3.1 | Communication integrity | a plaintext OT or IT protocol (`plaintext-check`) |
| SR 4.1 | Information confidentiality | a plaintext management protocol carrying credentials (telnet, SNMP v1/v2c) |
| SR 5.1 | Network segmentation | an OT protocol answering from the IT side: the conduit is open |
| SR 7.7 | Least functionality | unnecessary ports and protocols open on a zone (`discover --it-ports`) |

## Zones and conduits

62443 frames OT security as **zones** (groups of assets with a common
security level) joined by **conduits** (the controlled paths between them).
elSereno's `--vantage` label and `--it-ports` sweep are built for this
model: run `discover --it-ports` from one zone and `scan --vantage <zone>`
from another, and a finding that appears from the wrong vantage is a
conduit that is not enforcing the segmentation SR 5.1 requires.
