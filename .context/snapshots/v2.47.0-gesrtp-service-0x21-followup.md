# Snapshot — v2.47.0: GE-SRTP service-0x21 follow-up

Single-chunk cycle. Closes the long-deferred carryover
from v1.28/v1.x. Extends the v1.28 service-0x21 parser
with additional family coverage + raw-hex export for
operator post-processing + serial-number heuristic.

## What changed

### `internal/protocols/gesrtp/wire/wire.go`

8 new GE PLC family prefixes (v2.47):

  - `EFM3530`   — EX2100e turbine controller
  - `RX3iCPE`   — RX3i CPE100/CPE115 explicit sub-family
  - `RX3iCPL`   — RX3i CPL410 / Linux PLC
  - `VersaPro`  — legacy engineering tool fingerprint
  - `S90Micro`  — Series 90 Micro compact line
  - `PAC9000`   — legacy PAC9000 family
  - `PACMotion` — PACMotion controller
  - `PACEdge`   — PACEdge edge-compute device

These are additive — existing matches still resolve via
the older prefixes (PACSystems, IC693/695/697/200, RX3i,
RX7i, IS220/215, etc.).

### LongStatusInfo extended

  - **`RawHex string`** (v2.47+): first 128 bytes of the
    service-0x21 response as lowercase hex. Operators with
    physical PLCs can paste this into a hex editor to
    validate / extend the parser when their device's
    encoding differs from the nmap NSE reference.
  - **`SerialHint string`** (v2.47+): best-effort
    serial-number-like ASCII run extracted from the bytes
    immediately after the firmware tag. Looks for
    `[A-Z0-9-]{8,16}` in a 64-byte window.

### `ParseLongStatus`

  - Returns `RawHex` even when no Model marker is found
    (lets operators decode novel responses).
  - On a known-model response, fills Model + Firmware (as
    before) + RawHex + SerialHint.

## Honest scope

  - The serial heuristic is a defensible guess but vendors
    don't agree on serial-number alphabet/length. Operators
    should validate before treating SerialHint as
    authoritative.
  - RawHex is capped at 128 bytes — typical service-0x21
    responses fit; longer payloads truncate (operators
    extending the parser can lift the cap locally).
  - Still no validation against a physical Mark VIe /
    RX3i / PACSystems device. The v1.28-chunk-2 HONEST
    SCOPE NOTE remains.

## Build sizes

Unchanged (data + heuristic in stdlib).

Adds ~110 LoC + the 8 prefix table entries.
