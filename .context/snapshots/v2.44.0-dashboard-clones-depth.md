# Snapshot — v2.44.0: dashboard clones view + depth control

Single-chunk cycle. Upgrades the v2.14 clones view with
the v2.23 `?depth=N` chain traversal + visual indentation
+ per-depth summary tally.

## What changed

### HTML

- Removed duplicate-ID v2.14 minimal clones panel.
- Single canonical `schedule-clones-view` div with:
  - depth input (1..10, default 3, onchange re-fetches).
  - schedule-clones-summary span ("12 total · d1:3 ·
    d2:5 · d3:4").
  - 5-column table: Depth | Name (indented) | ID
    (12-char prefix) | Operator | Created.

### JS

- Module-level `clonesSchedID`/`clonesSchedName` state so
  `reloadClones()` (depth-input onchange) re-hits without
  re-opening.
- Indent per row = `"· " × (depth - 1)` so chains read
  visually like an ASCII tree.
- Per-depth tally shown in summary.
- `window.{openClonesView,closeClonesView,reloadClones}`
  exposed.

## Behavior

  - Click "Clones" on a schedule row → view opens with
    depth=3.
  - Change depth → live re-fetch.
  - Empty result → "no clones of this schedule (depth=N)".
  - 404 (source schedule deleted) → caught + surfaced.

## Honest scope

  - No click-through-to-clone (clicking a row doesn't
    open that clone's own clones-view). Operators
    navigate via the main table.
  - Indent rendered with `·`s + leading spaces — fine in
    most fixed-width contexts, can be ASCII-art-ier in a
    follow-up.

## Build sizes

Unchanged. JS-only delta.

Adds ~70 LoC net (-40 v2.14 removed, +110 v2.44 upgraded).
