# Snapshot, v2.64.0: OT-exposure probes, five standards catalogues, scan pacing

Everything merged to `main` between v2.63.2 (2026-10-19) and
2026-11-08. The authoritative list is `CHANGELOG.md` `[2.64.0]`; this
is the cycle's shape.

## What landed

- **OT exposure (2026-10-27).** Transport-keyed port catalogue with an
  IT-management category (`discover --it-ports`, `plaintext-check
  --list-ports`); opt-in probes `tristation` (UDP 1502, active and
  passive from pcap/pcapng) and `profinet-cm` (UDP 34964, EPM lookup);
  Conpot honeypot verdict in the S7 probe; `scan --vantage`; offensive
  `creds-check reuse`.
- **Audit fixes (2026-10-27).** Four medium (strict audit verification
  PITF-108, verified-peer TLS for Postgres and creds reuse PITF-107,
  vault zeroize on serve exit) and nine low-severity fixes
  (PITF-109/110/111). Go 1.26.10 for GO-2026-6809.
- **Scan pacing (PR #41, merged 2026-11-01/02).** `--profile` pacing
  for `scan` and `discover`, `--probe-timeout`, cancel-aware probes,
  Ctrl-C exits 130 (PITF-112/113/114).
- **Standards (2026-10-27 and 2026-11-07/08).** `internal/standards`
  carries five catalogues in every output: NIST SP 800-82 r4 IPD, MITRE
  ATT&CK for ICS v20, ISA/IEC 62443-3-3, NIST CSF 2.0 and DOE/INL
  Cyber-Informed Engineering. `standards --standard
  nist|attack-ics|iec62443|csf2|cie`.
- **Dependencies.** Dependabot #43: koanf 2.4.1, yaml v3.0.6,
  golang.org/x/net v0.62.0 (CVE-2026-78661).

## Honest scope

- SP 800-82 r4 is still an Initial Public Draft (comments until
  2026-11-30): table numbers and wording must be re-checked against the
  final publication.
- The protocol-to-standard mappings are elSereno's reading; NIST,
  MITRE, ISA, IEC, DOE and INL have not reviewed them.
- `tristation` wire validation is against a synthetic capture, and
  `profinet-cm` is spec-grounded; neither has been run against a live
  device.
- The release is built by the tag-push workflow (cosign keyless, SLSA
  v1, GHCR image), as v2.63.2 was. Install docs move to v2.64.0 only
  after the release is published and its signatures verified.
