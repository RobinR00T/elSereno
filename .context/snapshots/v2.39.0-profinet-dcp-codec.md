# Snapshot — v2.39.0: PROFINET DCP wire codec

Single-chunk cycle. Closes the last deferred roadmap item
(PROFINET, originally vNext from v1.50). v2.39 ships the
protocol-level codec; live L2 capture remains vNext behind
a raw-socket build tag.

## Why a codec, not a Probe plugin

PROFINET DCP runs **directly over Ethernet** (EtherType
0x8892, multicast MAC 01:0E:CF:00:00:00) — L2, no IP, no
TCP. The elsereno Probe(ctx, Target) framework expects an
(IP, port) target. Until raw-socket scanning lands
(gopacket + CAP_NET_RAW), v2.39 delivers:

  1. Pure-stdlib wire encoder for DCP Identify requests.
  2. Wire decoder with vendor / device-ID / station-name /
     IP-config extraction.
  3. Foundation for an offline pcap-decode verb (CLI
     follow-up) so operators can pipe
     `tcpdump -i eth0 ether proto 0x8892` through us
     without writing gopacket code.

## What ships

`internal/protocols/profinet/`:

  - **doc.go** — full design + frame layout in ASCII
    diagram.
  - **wire.go** (~310 LoC):
    - Constants: EtherTypePROFINET, MulticastIdentify
      MAC, FrameID enum, Service IDs, Service types,
      Option codes (IP/Device/DHCP/Control/All),
      Suboption codes for OptionDevice + OptionIP.
    - `Header`, `Block`, `Frame` types.
    - `DecodeDCP(buf)` — tolerant TLV walker; partial
      result + error on truncation.
    - `EncodeDCPIdentifyAll(xid)` — 18-byte request that
      matches every device on the segment.
    - `ParseIdentifyResponse(f)` → `IdentifyResponse`
      (NameOfStation, VendorID, DeviceID, DeviceRole,
      OEMDeviceID, IP, Subnet, Gateway).
    - `FormatDeviceRole(role)` — bitfield → human
      string (IO-Controller / IO-Device /
      IO-Multidevice / PNIO-Supervisor, plus-joined).
    - `printableASCII` filter for non-conformant
      station-name padding (NULs common in real
      firmware).
  - **wire_test.go** (~190 LoC, 5 tests):
    - EncodeIdentifyAll shape check.
    - Decode round-trip.
    - TooShort rejection.
    - Siemens-style synthetic response with 4 blocks
      (NameOfStation, DeviceID, Role, IP) round-trips
      fully through `ParseIdentifyResponse`.
    - FormatDeviceRole table-driven (6 cases).
    - BlockTruncation error path.

## Defensive read-only

Set / FactoryReset / Stop ServiceIDs are NOT generated by
this package. A future offensive cycle behind
`-tags offensive` may add them with the triple-confirm
guard (per ADR-004). v2.39 is identification + decode only.

## Honest scope

  - **No live capture.** sending requires raw L2 sockets +
    root cap. Stdlib net package doesn't expose them.
    gopacket is a heavy new dep; defer.
  - **No CLI verb yet.** The codec is callable from Go
    code; an `elsereno profinet decode <hex>` verb is a
    small follow-up cycle.
  - **No plugin registration.** This package is a wire
    codec, not a `core.Protocol`. The (host, port) Probe
    framework doesn't fit L2 protocols.
  - **VLAN-tagged frames need caller-side stripping.** We
    document the 14-byte (or 18-byte VLAN) Ethernet
    header expectation; caller pre-strips before calling
    DecodeDCP.
  - INSTALL.md unchanged (defensive default; no install
    delta).

## Build sizes

Unchanged across all 3 variants (pure stdlib).

Adds ~310 LoC wire + 190 LoC tests + 60 LoC doc.

## Carryover

  - **vNext** (`-tags profinet_raw`): gopacket-based live
    sniffer + L2 sender. Requires CAP_NET_RAW on Linux,
    BPF devices on macOS. Build-tag gated so the default
    build stays dep-clean.
  - **vNext**: CLI verb `elsereno profinet decode <hex|file>`
    that piping `tcpdump -xx -i eth0 ether proto 0x8892`
    through.
  - **vNext**: GSDML database for vendor/device-id →
    human-name resolution (e.g. 0x002A → "Siemens",
    0x0123 → specific model).
  - **vNext**: offensive Set support behind triple-confirm
    (ADR-004 pattern; matches Modbus / S7 / BACnet).
