# Snapshot — v2.60.0: /metrics endpoint + pool collector wiring

Single-chunk cycle. The Prometheus collector (v2.55) +
adapter (v2.58) existed; v2.60 mounts `GET /metrics`
so Prometheus scrapers can collect.

## Plumbing

`internal/web/server.go`:

```go
type Options struct {
    ...
    MetricsHandler http.Handler  // v2.60+
}
```

In `NewServer`:

```go
if opts.MetricsHandler != nil {
    mux.Handle("/metrics", opts.MetricsHandler)
}
```

Nil → route stays unbound (operators can run without
Prometheus).

`cmd/elsereno/cmd_serve.go`:

```go
out.MetricsHandler = buildMetricsHandler(out.PoolStatter)
```

`buildMetricsHandler`:
  1. Grabs `telemetry.Global()` (the singleton Metrics).
  2. If a pool exists, constructs a `PoolCollector` over
     a `handlersToTelemetryStat` shim that bridges the
     two PoolStat shapes (handlers ↔ telemetry).
  3. Registers via `m.Registry().Register(collector)`.
  4. Returns `m.Handler()`.

## Adapter bridge

The two `PoolStat` declarations (`handlers.PoolStat` and
`telemetry.PoolStat`) are intentional — each package
stays free of cross-deps. The `handlersToTelemetryStat`
shim copies field-by-field on each `Stat()` call. Cheap
+ keeps the dep graph clean.

## Tests (+2)

`internal/web/server_metrics_test.go`:
  - **TestMetrics_Mounted**: stub MetricsHandler with
    "# HELP test 1" body; GET /metrics returns it.
  - **TestMetrics_Unmounted**: nil MetricsHandler; GET
    /metrics returns dashboard HTML (catch-all) — the
    assertion is "body MUST NOT look like Prom expo",
    not "must be 404" (the "/" handler catches
    /metrics in that case).

## Honest scope

  - No authn on /metrics. Operators can wrap behind a
    reverse proxy + IP allowlist if they don't want it
    public. (Standard Prometheus deployment pattern.)
  - PoolCollector only registers when a pool exists.
    Memory-mode deployments still get the rest of the
    elsereno_* metrics, no errors.
