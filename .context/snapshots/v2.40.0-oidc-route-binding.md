# Snapshot — v2.40.0: per-route OIDC RequireRole binding

Single-chunk cycle. v2.38 added the auth package + Verifier;
v2.40 wires it into every /api/v1/schedules/* route with a
declarative (pattern → min-role) table.

## What changed

### `internal/web/handlers/api.go`

  - `APIV1Deps` gains `AuthVerifier *auth.Verifier`.
    Nil OR `v.Enabled()==false` → back-compat dev mode
    (all routes pass through unchanged; preserves
    X-Operator workflow + entire existing test suite).
  - `mountScheduleRoutes` refactored: per-route entries
    via `scheduleRoutes()` table with explicit role
    declaration.
  - New `scheduleRouteEntry{pattern, role}` struct.
  - `wrapWithRole(v, role, h)` composes the middleware
    conditionally — nil verifier returns h unchanged
    (zero overhead when disabled).

### Role assignment

```
Reads (GET)                 → viewer
Single-schedule mutations   → operator
  POST /schedules
  PUT  /schedules/{id}
  DELETE /schedules/{id}
  POST /schedules/{id}/enable|disable|clone
Fleet-wide / destructive    → admin
  POST /schedules/tags/rename
  POST /schedules/bulk/enable|disable
  POST /schedules/import
```

19 routes total, all declared in one table.

### `internal/web/handlers/scans.go`

  - `operatorFromRequest` updated precedence:
    1. OIDC ctx-bound identity (auth.OperatorFromContext)
    2. X-Operator header (v1.58 fallback)
    3. ""
  - Token-bound identity always wins — header can't
    impersonate when OIDC is enforced.

## Honest scope

  - Per-route binding is currently SCHEDULES-only. /scans,
    /audit, /findings, /security still pass through (these
    are read-mostly + the audit chain is the authn record).
    Wider binding lands in a follow-up cycle once operators
    request it.
  - No config plumbing yet — `AuthVerifier` is constructed
    + injected manually in tests. The
    `auth.oidc.{issuer,audience,jwks_url}` koanf section is
    v2.43 carryover.
  - INSTALL.md unchanged (OIDC remains opt-in via
    AuthVerifier population; no install delta).

## Build sizes

Unchanged.

Adds ~70 LoC (api.go refactor) + 1 import.
