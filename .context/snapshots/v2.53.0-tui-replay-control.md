# Snapshot — v2.53.0: TUI replay pause + rate keybindings

Single-chunk cycle. v2.51 added playback progress; v2.53 lets
operators pause/resume + change rate mid-replay without
restarting.

## New keys (only when ReplayCtl attached)

  - **`space`** → toggle pause/resume.
  - **`[`** → halve playback rate. From uncapped (0) → 1.0/s.
  - **`]`** → double playback rate. No-op at uncapped.

Each press emits an audit-pane line:

```
(replay: paused)
(replay: resumed)
(replay rate: 2.50/s)
(replay rate: uncapped)
```

## Shared-pointer control

New `feeds.ReplayControl` struct + factory:

```go
ctl := feeds.NewReplayControl(initialRate)
replay := feeds.Replay{Path: ..., Control: ctl}
opts := tui.RunOpts{ReplayCtl: ctl}
```

`feeds.ReplayControl` exposes:
  - `Rate() float64`, `SetRate(r)`, `HalveRate()`, `DoubleRate()`.
  - `Paused() bool`, `TogglePause() bool`.
  - `WaitIfPaused() bool` (called by feed before each line).
  - `PaceDelay() time.Duration` (re-read by feed for live
    rate changes).

Concurrency: `atomic.Int64` for rate (basis-points to avoid
float-atomic dance), `atomic.Bool` + `sync.Cond` for pause
broadcast.

## Interface in `internal/tui`

```go
type ReplayController interface {
    TogglePause() bool
    Paused() bool
    HalveRate()
    DoubleRate()
    Rate() float64
}
```

Defined in tui package so `Model.ReplayCtl` doesn't import
feeds (would create a cycle).

## Stream variant

New `streamNDJSONDynamic(ctx, src, emit, pacer func() time.Duration)`
wraps the existing fixed-rate streamer with a per-line
pacer callback. `Replay.stream` uses it when `Control != nil`
so rate changes take effect by the next line.

## Tests (+7)

`replay_control_test.go`:
  - RateBasics: SetRate/Rate roundtrip.
  - HalveDouble: 4→2→4.
  - HalveFromUncapped: 0→1.
  - DoubleAtUncapped: 0→0 (no-op).
  - PauseToggle: TogglePause flips + returns new state.
  - WaitBlocks: paused goroutine blocks until unpause from
    another goroutine.
  - PaceDelay: 10/sec → 100ms; 0 → 0.

## Honest scope

  - `cmd_tui.go` needs to construct ReplayControl + pass
    via RunOpts when `--replay`. That CLI wiring is a
    small follow-up (today the keys exist + are
    tested; library callers can use them).
  - No `step` key (single-frame advance). Spacebar already
    covers the "look at this in detail" workflow via
    pause + scroll.
