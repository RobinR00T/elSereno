# Snapshot — v2.55.0: Prometheus pool-stats collector

Single-chunk cycle. v2.52 added `/api/v1/health/pool`
(JSON snapshot for the dashboard); v2.55 adds the
Prometheus exposition of the same stats so operators can
graph them in Grafana / alertmanager.

## What ships

`internal/telemetry/pool_collector.go`:
  - `PoolStatProvider` interface (`Stat() *PoolStat`).
  - `PoolStat` flat struct mirroring pgxpool.Stat fields
    (re-declared here so the telemetry package is
    pgxpool-dep-free).
  - `PoolCollector` implements `prometheus.Collector`
    with 12 metric Descs.
  - `NewPoolCollector(provider)` ctor.
  - `Describe` + `Collect` per Prometheus interface.
    Lazy: each scrape re-reads the snapshot.

## Metrics exposed

7 counters (`*_total` suffix):

  - `elsereno_pool_acquire_count_total`
  - `elsereno_pool_acquire_duration_seconds_total`
  - `elsereno_pool_canceled_acquire_count_total`
  - `elsereno_pool_empty_acquire_count_total`
  - `elsereno_pool_new_conns_count_total`
  - `elsereno_pool_max_lifetime_destroy_count_total`
  - `elsereno_pool_max_idle_destroy_count_total`

5 gauges:

  - `elsereno_pool_acquired_conns`
  - `elsereno_pool_constructing_conns`
  - `elsereno_pool_idle_conns`
  - `elsereno_pool_max_conns`
  - `elsereno_pool_total_conns`

## funlen split

NewPoolCollector → buildCounters + buildGauges helpers
+ `poolDesc()` tiny ctor wrapper to skip `nil, nil`
boilerplate.

## Tests (+3)

  - TestPoolCollector_HappyPath: 7 expected name→value
    pairs scrape correctly via Registry.Gather.
  - TestPoolCollector_NilProvider: no panic, zero
    samples emitted.
  - TestPoolCollector_NilStat: provider returns nil →
    zero samples.

## Wiring path (deferred)

cmd_serve constructs a shim provider that adapts
`*pgxpool.Pool.Stat()` → `telemetry.PoolStat` + passes
to NewPoolCollector + registers in the existing
prometheus.Registry from internal/telemetry. That
bootstrap edit lands when operators need it.

## Honest scope

  - No labels (per-pool / per-DB). One pool per process
    today; multi-pool deployments would need label
    extension.
  - No histograms for acquire-duration distribution
    (Stat exposes only cumulative sum). Adding requires
    a custom HookAcquire wrapper.

Unchanged. prom client already a dep.

Adds ~140 LoC collector + 100 LoC tests.
