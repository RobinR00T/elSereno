# Snapshot — v2.43.0: auth.oidc koanf config stanza

Single-chunk cycle. Closes v2.40 carryover. v2.38 + v2.40
gave us the auth package + per-route binding; v2.43 declares
the YAML/koanf config section so operators can wire OIDC
declaratively from elsereno.yaml instead of constructing
Verifier manually.

## YAML shape

```yaml
auth:
  oidc:
    issuer:     "https://idp.example.com"
    audience:   "elsereno"
    jwks_url:   "https://idp.example.com/.well-known/jwks.json"
    clock_skew: 60s   # optional; defaults to 60s
```

Empty/missing values → OIDC disabled. Back-compat default
preserves X-Operator dev-mode workflow.

## Go shape

```go
type Config struct {
    ...
    Auth AuthConfig `koanf:"auth" yaml:"auth"`
}

type AuthConfig struct {
    OIDC OIDCConfig `koanf:"oidc" yaml:"oidc"`
}

type OIDCConfig struct {
    Issuer    string        `koanf:"issuer"`
    Audience  string        `koanf:"audience"`
    JWKSURL   string        `koanf:"jwks_url"`
    ClockSkew time.Duration `koanf:"clock_skew"`
}

func (o OIDCConfig) Enabled() bool   // all 3 URLs non-empty
```

## Footgun protection

`Enabled()` requires ALL THREE URL fields. Setting only
issuer (and forgetting jwks_url) was the highest-likelihood
operator error. Partial config → treated as disabled →
fail-open to dev mode is BETTER than fail-quiet-pass on
unverified tokens.
