# Snapshot — v2.41.0: PROFINET CLI decode + encode verb

Single-chunk cycle. Closes v2.39 carryover. v2.39 shipped
the wire codec; v2.41 exposes it via a CLI verb so operators
can decode tcpdump captures without writing Go code.

## CLI surface

```
elsereno profinet decode --hex 'feff0501...'
elsereno profinet decode --file capture.bin [--strip-l2 14|18]
elsereno profinet decode --file capture.bin --json
elsereno profinet encode-identify --xid 0xCAFEBABE
```

  - `--hex`: tolerates whitespace, 0x prefix, `:` and `-`
    separators (matches tcpdump -xx output formatting).
  - `--file`: binary capture (max 64 KB).
  - `--strip-l2 N`: skip the first N bytes (Ethernet=14,
    VLAN-tagged=18) before decoding.
  - `--json`: machine-readable shape for jq pipelines.
  - `encode-identify` emits an 18-byte DCP RT frame (no
    Ethernet header) for raw-socket senders.

  - No pcap-file (.pcap with libpcap header) support;
