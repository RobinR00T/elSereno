# Snapshot — v2.54.0: OpenAPI doc for v2.10/v2.11/v2.45/v2.49/v2.52

Single-chunk cycle. The endpoints added by v2.10 (`/clones`),
v2.11 (`/stats/timeseries`), v2.45 (`/runs ?since/until`),
v2.49 (`/export ?format=ics`), and v2.52 (`/health/pool`)
were live but undocumented. v2.54 backfills the OpenAPI 3.1
spec so the dashboard's "API · openapi" link, the generated
docs/openapi.yaml, and any external code-gen consumers see
them.

## What's new in the spec

### v2.45 — `/api/v1/schedules/{id}/runs`

Description extended to document `?since=&until=` (RFC3339);
mutual exclusion with cursor; inverted range → 400.

### v2.10/v2.23 — `/api/v1/schedules/{id}/clones`

NEW. Describes `?depth=1..10`, `clone_depth` in response
rows for ASCII-tree rendering, 400 on bad depth, 404 on
missing source.

### v2.11 — `/api/v1/schedules/{id}/stats/timeseries`

NEW. `?bucket=hour|day|week` + `?days=N`. Documents the
`{schedule_id, bucket, window_days, series: [{...}]}`
shape + Memory vs PG bucket-fill behaviour.

### v2.49 — `/api/v1/schedules/export`

Description extended to document `?format=ics` (RFC 5545,
interval→RRULE FREQ=HOURLY/DAILY, cron→DESCRIPTION,
disabled→STATUS:CANCELLED).

### v2.52 — `/api/v1/health/pool`

NEW. Full pgxpool stat surface documented. 503 when no
pool configured.

## funlen refactor

`schedulesObservabilityPaths()` would have been 95 lines
with everything inline. Split:
  - `schedulesObservabilityPaths()`: /audit + /stats +
    /runs (3 paths).
  - `schedulesExtendedObservabilityPaths()`: /clones +
    /stats/timeseries + (appended) /schedules/audit
    (prune).
  - `schedulesPruneAuditPath()`: lifted to its own helper
    so the extended fn stays clean.
